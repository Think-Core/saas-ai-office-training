请根据当前工作区中的以下资料，生成一个可复用的会议纪要 Skill 创建文档：

1. 当前会议的转写稿或会议记录；
2. 会议纪要模板；
3. 上次会议决策记录；
4. 参会角色与职责。

Skill 名称：`meeting-to-actions`（或自定义）

Skill 目标：
将项目会议转写或会议记录，转换为标准会议纪要、决策表、行动项表、未决问题清单和会后跟进消息草稿。

请为 Skill 编写完整说明，必须包含：
1) 触发条件；
2) 适用输入；
3) 不适用场景；
4) 处理步骤；
5) 信息分类规则；
6) 行动项字段定义；
7) 输出格式；
8) 来源和时间戳要求；
9) 不确定信息处理规则；
10) 人工确认节点；
11) 禁止自动执行的动作；
12) 质量检查清单；
13) 至少 3 个测试用例。

必须遵循以下规则：
1) 区分事实、讨论、建议、决定和未决问题；
2) 没有明确负责人的任务写“待认领”；
3) 没有明确日期写“待确认”；
4) 不根据语气猜测负责人或截止时间；
5) 不把“可以考虑”“后续看看”写成正式决定；
6) 关键数字、人名、日期和术语必须回到原文核验；
7) 不直接创建任务；
8) 不发送通知；
9) 不覆盖原始会议记录；
10) 所有输出都要保留来源依据。

请将 Skill 内容输出为适合直接创建 Skill 的 Markdown 文档。
