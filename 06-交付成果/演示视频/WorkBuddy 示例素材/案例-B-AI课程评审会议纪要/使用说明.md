# 使用说明

## 案例目标

把项目评审会的会议转写，整理成标准纪要、决策表、行动项表和会后跟进消息。

## 使用顺序

1. `02-Prompts/B01-创建会议纪要Skill.md`
   - 作用：根据会议资料和通用会议方法，生成可复用的会议纪要 Skill 创建文档。
   - 预期：得到 Skill 名称、触发条件、步骤、输出格式、边界和测试用例。

2. `02-Prompts/B02-使用Skill预分析会议记录.md`
   - 作用：调用刚创建的 Skill，先识别会议基本信息、议题、决定、行动项和待核验内容。
   - 预期：得到预分析结果，不生成最终纪要。

3. `02-Prompts/B03-生成会议纪要草稿.md`
   - 作用：将会议转写整理成正式纪要，并保留来源依据。
   - 预期：得到结论、讨论摘要、决策表、行动项表和未决问题。

4. `02-Prompts/B04-生成待办导入预览.md`
   - 作用：把行动项转换成任务导入预览，缺少负责人或日期的内容不创建。
   - 预期：得到按负责人分组的待办预览和待补充清单。

5. `02-Prompts/B05-生成会后跟进消息.md`
   - 作用：生成参会人版本和项目负责人的会后消息草稿。
   - 预期：得到两份只供人工确认的消息草稿，不发送。

6. `02-Prompts/B06-会议纪要质量检查.md`
   - 作用：检查事实、决定、建议、行动项是否混淆，检查责任人、日期和来源。
   - 预期：得到最终质量检查报告。

## 演示注意事项

先将 `01-原始素材` 文件夹加入工作区。B01 只生成 Skill 创建文档，不直接安装或创建 Skill。B02 至 B06 假设 Skill 已由用户根据 B01 创建完成。不直接创建任务、不发送消息、不修改原始转写稿。Prompt 是通用版本，可用于其他项目评审会议。
