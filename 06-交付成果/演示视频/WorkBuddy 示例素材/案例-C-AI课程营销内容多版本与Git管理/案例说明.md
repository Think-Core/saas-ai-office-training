# 案例说明

## 项目背景

一个虚拟项目需要面向不同客群（企业负责人、个人学习者）以及不同渠道（短文案、活动文案）准备营销内容。事实资料统一管理，不同客群版本独立表达，并能在客群版本基础上独立延伸出多个变体。

## 演示目标

1. 事实主版本与营销版本的分离；
2. 企业版、个人版基于主版本生成；
3. 客群延伸版本 C 和 D 在客群版本基础上独立延伸；
4. Git 多分支管理多版内容；
5. 多 Agent 协作完成事实核验、客群策略、文案生成、合规审核和主编汇总；
6. 最终版本审查。

## 分支结构

```
main（事实主版本 A）
├── marketing/enterprise（B1）
├── marketing/individual（B2）
    ├── marketing/short-c（C）
    └── marketing/campaign-d（D）
```

## 预设问题

既有营销文案初稿中含有效果承诺、绝对化表达和未经事实卡确认的工具名，需要在最终版本中清除或标注。
