本案例默认基于个人版生成。

父版本：个人版营销内容。

输入资料：
1. 品牌语气规范；
2. 合规与禁用表达。

输出：
1) 主标题 3 个，10 字以内；
2) 副标题 3 个，25 字以内；
3) 行动提示 3 个；
4) 一句话价值主张；
5) 事实来源映射。

要求：
1) 客群延伸版本 C 与父版本必须表达同一主题；
2) 不新增事实；
3) 不引入未经确认的具体工具名、客户案例和效率数据；
4) 保留与父版本的事实对应关系；
5) 生成建议提交标题：`feat: add short copy C derived from individual version`。
