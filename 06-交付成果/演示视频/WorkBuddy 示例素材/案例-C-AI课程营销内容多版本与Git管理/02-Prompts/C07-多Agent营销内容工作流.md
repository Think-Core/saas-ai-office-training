请设计一个“营销内容多版本生成与审核”多 Agent 工作流，并输出一张完整的工作流架构图。

总目标：
根据已确认的事实主版本，生成多个客群版本和客群延伸版本，并完成事实、表达和合规审核。

角色分工：
1) 事实核验 Agent：输出事实清单、来源映射、版本差异、冲突项和待确认项。
2) 客群策略 Agent：根据受众画像定义各客群版本的沟通重点、语气和禁区。
3) 文案生成 Agent：生成各客群版本和客群延伸版本。
4) 合规审核 Agent：检查事实、绝对化表达、效果承诺、版本和来源完整性。
5) Git 管理 Agent：记录父版本、分支关系、变更内容和提交说明。
6) 主编 Agent：只汇总已经通过事实和合规审核的内容。

请输出：
1) 每个 Agent 的输入、输出和禁止动作；
2) 角色之间的交接格式；
3) 哪些环节可以并行；
4) 哪些环节必须串行；
5) 哪些环节需要人工确认；
6) 客群延伸版本的接入方式（在客群版本基础上独立延伸）；
7) 一张完整的工作流架构图，使用 Mermaid `flowchart` 或 `graph` 表示。

要求：
1) 下游 Agent 只能读取上游已经确认的产物；
2) 不同分支不能各自维护互相矛盾的事实；
3) Git 记录不能替代事实和合规审核；
4) 不自动发布、发送或覆盖文件。
