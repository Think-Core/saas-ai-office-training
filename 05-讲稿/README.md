# 讲稿

当前授课讲稿按课程环节分为两份：

- `讲稿_基础讲解.md`：对应 33 页网页版 PPT，基础讲解总时长约 12 分钟，按部分逐步完成口语化调整。
- `讲稿_案例E1 E2.md`：对应周报生成和会议记录转行动计划两个实战案例，后续单独优化。

`讲稿.md` 保留为原 60 分钟课程的逐页基线，不再作为本轮时长压缩后的当前讲稿继续更新。

讲稿与 `04-网页版PPT/课件源代码/` 一起提交 Git，因此任意 commit/tag 都能恢复当时完全对应的课件和讲稿，不需要复制 v1、v2 文件。

阶段发布时在 `06-交付成果/发布记录.md` 登记 tag、commit 和交付文件。
