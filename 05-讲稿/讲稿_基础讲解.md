### `A-19`｜选择 Ask / Craft / Plan

- **讲述内容**：WorkBuddy 里有三种工作方式。Ask，就是问一问。比如，我们想先了解一份材料说了什么，或者这件事还缺哪些资料，就用 Ask。它会帮我们看资料、答问题，文件保持原样。Craft，就是直接做。任务想清楚了，比如整理表格、写一份文档、修改文件，就用 Craft。它会直接开始做。Plan，就是先把做法列出来。事情比较多，或者我们想先看看它准备怎么做，就用 Plan。它会先把要做的事情列出来，我们看过以后，可以对计划进行调整，再让它继续做。记住就行：想了解，用 Ask；直接做，用 Craft；先看方案，用 Plan。
- **建议时间**：45—55 秒。
- **录屏时机**：切换三种方式时，可各保留一帧界面作为录屏关键帧。
- **观看重点**：想了解、直接做、先看方案，对应 Ask、Craft、Plan。
- **可跳过内容**：不展开模式背后的技术实现。
- **互动备用话术**：大家可以想一个手头的任务：它现在更适合先问、直接做，还是先把方案理出来？

### `A-26`｜有了好工具，还要有好方法

- **讲述内容**：人和 Agent 一起做事，关键是分工清楚。人负责把要做什么、做到什么程度说清楚，也负责最后检查结果能不能用。Agent 负责理解要求、安排步骤、把事情往前推进。需要计算、作图、生成文件这些具体工作时，Agent把工作交给合适的工具去做。选择一个适合Agent的工具和工作方式，比要求Agent适应所有工具更高效，更好用。

### `A-27`｜文档处理的工作格式选择

- **讲述内容**：处理文档时，先把内容变成 Agent 更擅长处理的文本，再去调整最后的格式。比如，把 Word 文档转成 Markdown，先让它读、改、整理内容。内容确认以后，再把它放回 Word 里，交给 Agent 单独处理排版和格式。这样，Agent 可以先专心处理内容，速度更快，效果也更好。内容和格式分开做，是处理文档时合适的协作方式。
- **建议时间**：20—25 秒。
- **录屏时机**：无。
- **观看重点**：先处理文本内容，最后再处理 Word 等交付格式。
- **可跳过内容**：不讲 Markdown 的语法。
- **互动备用话术**：无。

- **讲述内容**：处理数据时，先把问题和口径说清楚。Agent 负责理解问题、安排步骤，工具负责计算、做图和生成结果。最后，人要检查数据有没有异常，结论是否符合要求，千万不要让Agent背后的模型生成数据，也就是让大模型心算。
- **建议时间**：15—20 秒。

### `A-31`｜长期任务：对话是工作现场，文件是组织记忆
