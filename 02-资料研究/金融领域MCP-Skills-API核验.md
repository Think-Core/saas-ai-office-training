# 金融领域 MCP、Skills、API 公开信息核验

核验日期：2026-07-28。用途：`A-23`“金融数据怎样接入 Agent？”页面。

## 核验结论

- 正确品牌名是“通达信”，不是“通信达”。财富趋势 2025 年年报披露正在推进 MCP 服务接口上线；公开转载的“通达信趋势财经”文章进一步使用“通达信 MCP”产品名。课件只写“通达信 MCP”，不扩展未经官方产品页确认的具体工具数量。
- 同花顺问财 SkillHub 已公开上线；同花顺官方站转载的投资者互动信息确认 iFinD 已推出金融数据 MCP 工具和 Skills 技能包；同花顺数据接口官网确认 iFinD 数据接口支持 SDK 与 HTTP API。课件统一写“问财 SkillHub / iFinD MCP / iFinD 数据接口”。
- 东方财富官方页面确认“妙想 Skills”，并说明其将金融数据能力与投研场景结合。公开页面中的 Skills 数量随版本变化，课件不写固定数量。
- Wind 官方 AIFin Market 页面明确采用开放 MCP 协议，并提供 Wind 金融 Skills。产品名统一写作“AIFin Market”。

## 课件表达边界

- 本页用于建立市场认知，不比较产品优劣、不判断采购对象。
- 不写未经公开页面稳定确认的工具数量、数据覆盖数量、价格或可用权限。
- 页面只解释三种入口的层次差异：MCP 连接数据和工具；Skills 封装研究流程；API 支持程序化取数。
